คู่มือการอ่าน Daily Machine Check

ทีมช่างตรวจเครื่องวันละ 2 พลัด (☀ พลัดเข้า / ☾ พลัดดึก) ผ่าน Microsoft Forms · Dashboard สรุปว่าเครื่องพร้อมใช้งานกี่เครื่อง

แผงสถานะด้านบน

  • ความพร้อมใช้งาน % = เครื่องที่ไม่เสียเลยทั้ง 2 พลัด ÷ เครื่องทั้งหมดของคลัง · เขียว = ปกติทุกเครื่อง · ส้ม = มีเครื่องเสีย
  • เสีย / ต้องซ่อม = เครื่องที่พบเสียอย่างน้อย 1 พลัดในวันที่เลือก
  • แถบพลัดเข้า / พลัดดึก = ตรวจแล้วกี่เครื่อง (เขียว ปกติ · แดง เสีย · เทา ยังไม่ตรวจ)

สถานะแต่ละเครื่อง

  • ✓ ปกติ ✕ เสีย ◷ ยังไม่ตรวจ
  • แถวที่มีเครื่องเสียมีแถบแดงด้านซ้าย · กด "ดูเฉพาะที่เสีย" เพื่อกรอง

ประวัติย้อนหลัง

  • เลือกช่วง 7 / 14 / 30 วัน · ตาราง สีเขียว = ปกติ · ส้ม = เสีย 1 พลัด · แดง = เสียทั้งวัน · ช่องที่มีกรอบ = วันที่เลือก
  • บันทึกรายวัน: วันไหนเสียเครื่องอะไร พลัดไหน · กด "เฉพาะวันที่มีเสีย" เพื่อดูแค่วันที่มีปัญหา
